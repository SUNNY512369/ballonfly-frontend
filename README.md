# Ballonfly Frontend (v2, naya UI)

Purana UI/UX hata diya gaya hai. Ab naye design ke mutabiq screens ek ek kar ke lag rahi hain.

- `src/styles/theme.css`: colors/fonts (dark navy + cyan/blue/purple)
- `src/lib/api.js`: backend URL (`VITE_API_BASE`) aur login session
- `src/components/Logo.jsx`: naya Ballonfly logo
- `src/App.jsx`: app shell (screens yahan judengi)

Chalane ke liye: `npm install` phir `npm run dev`. Build: `npm run build`.
